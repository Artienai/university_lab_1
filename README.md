# Лабораторная работа № 1. Университет

Консольная система учёта студентов, учебных дисциплин и оценок.

## Запуск

Требуется Python 3.10 или новее. Дополнительные библиотеки не нужны.

```bash
python main.py
```

## Типы записей

- `students`: `name`, `group`;
- `courses`: `title`, `hours`;
- `enrollments`: `student_id`, `course_id`, `grade` (от 2 до 5).

Запись `enrollment` связывает студента с дисциплиной и хранит оценку. Нельзя удалить студента или дисциплину, если на них ссылаются записи об оценках.

## Работа с файлами

Программа поддерживает чтение и запись данных в формате JSON. Для XML приведён пример структуры хранения в `data/university.xml`, однако программное чтение и запись XML не реализованы.

## Состав проекта

- `domain/models.py` — классы предметной области и собственное исключение;
- `domain/repository.py` — протокол репозитория;
- `application/university_service.py` — CRUD-операции и проверки связей;
- `infrastructure/file_repository.py` — хранение данных в JSON;
- `presentation/console.py` — консольное меню;
- `main.py` — запуск программы;
- `tests/` — автоматические проверки.

# Учёт университета — слоистый проект на Python

Минимальная консольная система для учёта студентов, учебных дисциплин и оценок. Проект написан на Python 3.10+, без сторонних зависимостей.

## Запуск в PyCharm

1. Склонируйте репозиторий или скачайте проект.
2. В PyCharm выберите **File → Open** и откройте папку `university_lab_1`.
3. Укажите Python 3.10 или новее как интерпретатор проекта.
4. Откройте `main.py` и нажмите **Run**.
5. Пользуйтесь консольным меню: создавайте, просматривайте, изменяйте и удаляйте записи, а также сохраняйте и загружайте данные в JSON.

Запуск из терминала из корня проекта:

```bash
python main.py
```

## Слои

```text
main.py                              Сборка зависимостей и запуск приложения
presentation/console.py              UI: input/print, меню и обработка ошибок
application/university_service.py    Бизнес-логика, CRUD и проверка связей
domain/models.py                     Модели Student, Course, Enrollment и UniversityError
domain/repository.py                 Контракт хранилища UniversityRepository
infrastructure/file_repository.py    Чтение и запись данных в JSON
data/university.json                 Пример данных университета в JSON
data/university.xml                  Пример структуры данных в XML
tests/test_university.py              Unit-тесты сервиса и файлового хранилища
```

Поток вызова: **Console → UniversityService → UniversityRepository ← FileRepository**.

`UniversityService` зависит от контракта `UniversityRepository`, а не от конкретного файлового формата. Реализация `FileRepository` отвечает за чтение и запись JSON. Поэтому файловое хранилище можно заменить другой реализацией, не переписывая правила предметной области и консольное меню.

## Предметная область

В проекте используются три типа записей:

- **Student** — студент: ID, ФИО и номер группы.
- **Course** — учебная дисциплина: ID, название и количество часов.
- **Enrollment** — результат студента по дисциплине: ID, ID студента, ID дисциплины и оценка.

Запись `Enrollment` связывает студента с дисциплиной. Она хранит внешние ключи `student_id` и `course_id`, а также оценку.

## Работа с данными

Программа поддерживает чтение и запись JSON. Пример структуры находится в `data/university.json`.

Файл `data/university.xml` показывает структуру хранения данных в XML, но программное чтение и запись XML в этой версии не реализованы.

## Проверка тестов

Из корня проекта:

```bash
python -m unittest discover -s tests -v
```

Сторонние библиотеки для запуска программы и тестов не требуются.

## Примеры бизнес-правил

- Нельзя создать запись с пустым ФИО, названием дисциплины или номером группы.
- ID и количество часов должны быть положительными целыми числами.
- Оценка должна находиться в диапазоне от 2 до 5.
- Нельзя записать студента на дисциплину, если студент или дисциплина не существуют.
- Нельзя удалить студента или дисциплину, на которые ссылаются записи `Enrollment`.
- При загрузке JSON проверяются структура данных, уникальность ID и корректность связей.
- При ошибке загрузки текущие данные не заменяются неполным набором.
